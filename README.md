# sistemski-softver-jednoprolazni-asembler
Realizacija asemblera, linkera i emulatora. Fajl sa izvornim aseblerskim kodom se prevodi u predmetni program. Više predmetnih programa linker pretvara u datoteku za inicijalizaciju memorije, koja uz navedenu -hex opciju komandne linije postaje ulaz emulatora.
